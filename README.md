# CMC Stats – companion site

Free lesson, calculators and articles for the CMC Stats course. Plain HTML, no build step.

- `index.html` – home page
- `calculator.html` – upper confidence limit for an SD and %RSD
- `intervals.html` – article: confidence, prediction or tolerance interval?
- `lessons/01/` – free lesson 01 practice set (interactive deck, PDFs, Excel files)
- `assets/` – shared styles, theme toggle, favicon

All data are synthetic. Training material only, not regulatory advice.
